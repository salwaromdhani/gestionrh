      Rapport Power BI

      Collez le lien de votre rapport Power BI publié pour l'afficher directement ici.

      Comment créer et intégrer le rapport ?

      1. Récupérer les données : exportez les employés en CSV avec le bouton ci-dessous, ou connectez Power BI Desktop directement à MySQL (base gestion_rh).
      2. Créer les visuels dans Power BI Desktop : nombre d'employés par département, masse salariale, salaire moyen par poste…
      3. Publier le rapport sur Power BI Service (bouton Publier).
      4. Dans le rapport en ligne : Fichier → Incorporer le rapport → Publier sur le web, puis copiez le lien.
      5. Collez le lien dans le champ ci-dessus et cliquez sur « Afficher le rapport ».
